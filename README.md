# ComfyWeb — ComfyUI 简易生成站

手机端优先的局域网图片生成网站：通过 API 调用另一台主机上的 ComfyUI，
把 ComfyUI 工作流变成简洁的生成表单（提示词 / 模型 / LoRA / 采样参数 / 数量），
带画廊，免构建、无 CDN，手机 + 桌面自适应。

## 使用

1. **设置**：首次访问进入「设置」页，填 ComfyUI 地址（如 `http://192.168.x.x:8188`），点「保存并测试连接」。
2. **导入工作流**：三种方式（「工作流 → 导入模板」）：
   - **工作流页一键导入**：连上 ComfyUI 后自动列出其「保存」过的工作流，点「快速导入」按默认参数入库，或「评审导入」先确认参数。同名模板自动加 `(2)`、`(3)` 后缀；面板上标出每个工作流已导入的份数，可直接删除已导入的副本。
   - **导入页从 ComfyUI 拉取**：同上但停留在评审步骤。
   - **粘贴 JSON**：在 ComfyUI 菜单「工作流 → 导出(API)」，把 JSON 粘贴进来。
   
   UI→API 转换支持 bypass/静音节点直通、Reroute、PrimitiveNode、Note 便签、字典型
   widgets_values；含子图的工作流请改用「导出(API)」。导入时自动识别可调参数
   （正/负提示词、模型、LoRA、采样参数、宽高等），可勾选显示、改标签、设默认值。
   在 ComfyUI 里给节点起的标题会自动变成表单标签。服务连上后后台自动预热模型与
   工作流列表，页面打开即有数据。
3. **生成**：「生成」页选模板 → 填表单 → 生成数量（工作流含 EmptyLatentImage 时走 batch_size，否则串行多次提交）→ 生成，实时显示采样进度与排队位置；提交后自动滚动到任务卡，生成完成手机震动提醒。表单草稿自动保存，完成的任务可「再来一次」原参数复刻（种子锁定），正面提示词下方可点选最近用过的提示词。点生成的图片在**页内灯箱**查看（多张上下滑动切换、点击进入放大可缩放平移），不跳页。
4. **画廊**：瀑布流图片墙，支持按提示词关键字、工作流、模型、LoRA、时间范围筛选；详情页主区域上下滑动/滚轮/方向键切换图片，点击图片进灯箱放大，下方简要信息栏点击展开完整参数（手机端字段/值上下堆叠）。任务落库时记录所用模型与 LoRA 供筛选，记录按「设置 → 数据」的保留条数自动清理。
5. **新装了模型/LoRA**：到「设置」页点「刷新模型列表」清掉缓存，生成页下拉即会更新。
6. **模型 / LoRA 页**：浏览和搜索 Civitai 上的模型与 LoRA（底模过滤、按下载/评分排序），详情页含底模、触发词（点击复制）、文件信息、"在 ComfyUI 里怎么用"指引。**数据本地库优先**：拉取过的搜索结果与模型详情（含描述/用法/版本）存 SQLite，之后加载直接读本地秒开，只有没有的才去 Civitai 拉取入库；点「刷新」忽略缓存强制在线更新当前结果。封面图经后端代理落盘缓存。顶部「已安装」面板会**后台自动识别**本机模型对应的 Civitai 条目（按文件名匹配，带出底模/触发词），也可点单个文件名搜索；需要代理或 API Token 时在「设置 → Civitai」配置，局域网设备无需直连 Civitai。
7. **提示词历史**：生成页表单会显示当前模板最近用过的提示词，点击回填；任务记录保留条数在「设置 → 数据」配置。
8. **提示词助手**：生成页正面提示词下方有「AI 润色 / AI 翻译」（可选风格：通用增强/细节丰富/动漫风/写实摄影/精简；模型下拉列出 LiteGate 网关的对话模型，选择记忆在本机），经本机 LiteGate 网关调用 LLM（`.env` 配 `LITEGATE_BASE/LITEGATE_MODEL/LITEGATE_API_KEY`）；所有提示词输入框输入时自动联想 Danbooru tag（`data/tags/danbooru.csv`，按热度排序、前缀优先，↑↓ 选择 / Enter 或点击补全；列表文件缺失时联想静默降级）。

## 架构

- Flask 3.1.3 多页应用（`app.py`），所有 ComfyUI 调用经本站后端代理（ComfyUI 默认无 CORS，浏览器无法直连）。
- `comfy_client.py`：HTTP API 封装 + 常驻 WebSocket 监听线程（progress_state / execution_* 事件，兼容旧版），断线自动重连；WS 不可用时轮询 `/history` 对账兜底。
- `workflow.py`：API 格式工作流解析（参数自动识别）与提交时值注入。
- `db.py`：SQLite（设置 / 模板元数据 / 任务 / 图片记录），模板 JSON 存 `data/workflows/`。
- 前端：Bulma 0.9.4 本地 vendor + hub-nav 同款皮肤（`static/css/skin.css`），原生 JS，零构建。

## 部署（本机）

- systemd 服务：`deploy/comfyweb.service`（绑 `127.0.0.1:5012`）
- nginx：`deploy/nginx-comfyweb.conf`（对外 29xxx 端口自签证书，http 301 跳 https；可选 basic auth，凭据放 `.env`，htpasswd 路径见配置）
- 导航页注册：按自己导航页的格式把端口加进服务列表

## 已知取舍

- 图片存在 ComfyUI 主机，画廊经代理流式读取；ComfyUI 侧删除输出文件或更换服务器地址后，旧记录图片会显示"图片缺失"占位。
- 不做 PWA；未使用 ComfyUI 新版 /api/jobs（经典 /prompt API 稳定够用）。
