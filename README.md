# ComfyWeb — ComfyUI 简易生成站

手机端优先的局域网图片生成网站：通过 API 调用另一台主机上的 ComfyUI，
把 ComfyUI 工作流变成简洁的生成表单（提示词 / 模型 / LoRA / 采样参数 / 数量），
带画廊，免构建、无 CDN，手机 + 桌面自适应。

## 使用

1. **设置**：首次访问进入「设置」页，填 ComfyUI 地址（如 `http://192.168.x.x:8188`），点「保存并测试连接」。
2. **导入工作流**：三种方式（「工作流 → 导入模板」）：
   - **工作流页一键导入**：连上 ComfyUI 后自动列出其「保存」过的工作流，点「快速导入」按默认参数入库，或「评审导入」先确认参数。同名模板自动加 `(2)`、`(3)` 后缀；面板上标出每个工作流已导入的份数，可直接删除已导入的副本。
   - **导入页从 ComfyUI 拉取**：同上但停留在评审步骤。
   - **粘贴 JSON**：在 ComfyUI 菜单「工作流 → 导出(API)」，把 JSON 粘贴进来。
   
   UI→API 转换支持 bypass/静音节点直通、Reroute、PrimitiveNode、Note 便签、字典型
   widgets_values；含子图的工作流请改用「导出(API)」。导入时自动识别可调参数
   （正/负提示词、模型、LoRA、采样参数、宽高等），可勾选显示、改标签、设默认值。
   在 ComfyUI 里给节点起的标题会自动变成表单标签。服务连上后后台自动预热模型与
   工作流列表，页面打开即有数据。
3. **生成**：「生成」页选模板 → 填表单 → 生成数量（工作流含 EmptyLatentImage 时走 batch_size，否则串行多次提交）→ 生成，实时显示采样进度与排队位置；提交后自动滚动到任务卡，生成完成手机震动提醒。表单草稿自动保存，完成的任务可「再来一次」原参数复刻（种子锁定），正面提示词下方可点选最近用过的提示词。点生成的图片在**页内灯箱**查看（多张上下滑动切换、点击进入放大可缩放平移），不跳页。
4. **批量生成**：「批量生成」页输入大概要求（主题/数量/风格补充）→ 点「AI 细化提示词」由 LiteGate LLM 产出任务清单(细化模型默认免费 nemotron,页内下拉可切换 deepseek-flash 等,选择记忆在本机)（内置两种管线风格参考：人物/图标/特效用 anima_turbo 英文标签风，纯背景/氛围用 z-image-turbo 中文自然句风）→ 清单可逐条改名称/管线/尺寸/提示词/种子、可删 → 开始生成。引擎按管线分组依次生成（同模型连跑，组间自动卸载显存），每张图落一条任务记录，实时进度 + 日志，完成后图片自动进画廊（工作流名「批量生成」，可按模型筛选）。每张图带上**批次主题与画面类型**（立绘/场景/背景/图标），画廊可直接按维度筛选。正/负提示词模板可保存复用（正向拼在每张图前，负向叠加到基础负面词）。GPU 温度保护默认关，在 `.env` 配 `BATCHGEN_GPU_TEMP=1` 开启（≥72°C 休 60s、≥78°C 休 180s；温度/利用率跨机自动采集：ComfyUI 装了 comfyui-hwapi 插件即得，或配 `COMFY_SSH=用户@GPU主机` 走 SSH）。**管线选型、提示词经验与翻车模式速查见 [docs/batchgen-playbook.md](docs/batchgen-playbook.md)**。
5. **画廊**：瀑布流图片墙，支持按提示词关键字、工作流、模型、LoRA、画面类型、批次主题、时间范围组合筛选；卡片右上角 ☆ 一键收藏，详情页顶栏星标同步。**收藏页**集中展示收藏的图片（同款瀑布流，可再次取消收藏）。详情页主区域上下滑动/滚轮/方向键切换图片，信息栏点击展开完整参数（手机端字段/值上下堆叠）。任务落库时记录所用模型与 LoRA 供筛选，记录按「设置 → 数据」的保留条数自动清理。
6. **新装了模型/LoRA**：到「设置」页点「刷新模型列表」清掉缓存，生成页下拉即会更新。
7. **模型 / LoRA 页**：浏览和搜索 Civitai 上的模型与 LoRA（底模过滤、按下载/评分排序），详情页含底模、触发词（点击复制）、文件信息、"在 ComfyUI 里怎么用"指引。**数据本地库优先**：拉取过的搜索结果与模型详情（含描述/用法/版本）存 SQLite，之后加载直接读本地秒开，只有没有的才去 Civitai 拉取入库；点「刷新」忽略缓存强制在线更新当前结果。封面图经后端代理落盘缓存。顶部「已安装」面板会**后台自动识别**本机模型对应的 Civitai 条目（按文件名匹配，带出底模/触发词），也可点单个文件名搜索；需要代理或 API Token 时在「设置 → Civitai」配置，局域网设备无需直连 Civitai。
8. **提示词历史**：生成页表单会显示当前模板最近用过的提示词，点击回填；任务记录保留条数在「设置 → 数据」配置。
9. **提示词助手**：生成页正面提示词下方有「AI 润色 / AI 翻译」（可选风格：通用增强/细节丰富/动漫风/写实摄影/精简；模型下拉列出 LiteGate 网关的对话模型，选择记忆在本机），经本机 LiteGate 网关调用 LLM（`.env` 配 `LITEGATE_BASE/LITEGATE_MODEL/LITEGATE_API_KEY`，自签证书网关配 `LITEGATE_INSECURE=1`）；所有提示词输入框输入时自动联想 Danbooru tag（`data/tags/danbooru.csv`，按热度排序、前缀优先，↑↓ 选择 / Enter 或点击补全；列表文件缺失时联想静默降级）。

## 架构

- Flask 3.1.3 多页应用:入口 `app.py` 只含应用工厂与启动,路由按功能域拆在 `views/` 包——
  `gen`(生成与工作流模板)、`gallery`(画廊与收藏)、`civitai`(模型/LoRA 页)、`ai`(AI 提示词助手)、
  `batch`(批量生成)、`admin`(设置/状态/健康检查)。模块可在「设置 → 功能开关」即时开关
  (存数据库),`.env` 里 `ENABLE_*` 是初始默认;某模块依赖缺失或加载失败只跳过该功能,
  其余不受影响。所有 ComfyUI 调用经本站后端代理
  （ComfyUI 默认无 CORS,浏览器无法直连）。
- `comfy_client.py`：HTTP API 封装 + 常驻 WebSocket 监听线程（progress_state / execution_* 事件，兼容旧版），断线自动重连；WS 不可用时轮询 `/history` 对账兜底。
- `workflow.py`：API 格式工作流解析（参数自动识别）与提交时值注入。
- `batchgen.py`：批量生成（AI 细化任务清单 + 内置 anima/z-image 管线预设 + 按模型分组的生成引擎）。
- `db.py`：SQLite（设置 / 模板元数据 / 任务 / 图片记录 / 批量生成提示词模板），模板 JSON 存 `data/workflows/`。
- 前端：Bulma 0.9.4 本地 vendor + hub-nav 同款皮肤（`static/css/skin.css`），原生 JS，零构建。

## 部署（本机）

- systemd 服务：`deploy/comfyweb.service`（模板，按实际用户/路径改过后安装；绑 `127.0.0.1:5012`）
- nginx：`deploy/nginx-comfyweb.conf`（对外 29xxx 端口自签证书，http 301 跳 https，basic auth 凭据在服务器 `/etc/nginx/*.htpasswd`）
- 导航页注册：按自己导航页的格式把端口加进服务列表

## 安全注意

- 应用只监听 `127.0.0.1`，对外一律经 nginx 反代（自签证书 + basic auth）；不要把应用端口直接暴露出局域网，更不要公开到公网。
- 所有 POST 接口有同源校验（跨站请求被 403），ComfyUI 地址只允许解析到内网的 http(s) 纯主机地址（防 SSRF），Civitai 图片代理仅限 civitai.com 域。
- `.env` 含 AI 网关密钥，已被 `.gitignore` 排除、不入库；仓库内所有示例配置均为占位符，部署时再填真实值。
- 跨机 GPU 监控走 SSH 时（`COMFY_SSH`）首次部署先 `ssh-keyscan` 录入主机密钥，应用不做首次自动信任。
- 数据都在 `data/` 目录（SQLite + 缓存），建议定期备份：`python scripts/backup.py [目标目录]`。

## 已知取舍

- 图片存在 ComfyUI 主机，画廊经代理流式读取；ComfyUI 侧删除输出文件或更换服务器地址后，旧记录图片会显示"图片缺失"占位。
- 不做 PWA；未使用 ComfyUI 新版 /api/jobs（经典 /prompt API 稳定够用）。
